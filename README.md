## The entry (112 characters)

> My Wi-Fi died for five minutes, so I had to talk to my family. They're nice people. I now pay extra for outages.

One funny line, a joke with a surprise turn: the setup is a familiar scene (Wi-Fi down, forced family time), and the punchline flips the usual moral — instead of treasuring the moment, the speaker treats the outage as a service worth paying for.

## Run it

```sh
node main.ts
```

`main.ts` writes the line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it is 1–200 characters, and verifies the written bytes match exactly.
